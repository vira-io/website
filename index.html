Vira zbiera biblioteki pisane przez spolecznosc HackerScript - zrodlowe (git), statyczne (.a), dzielone (.so) i natywne Rustowe (.rlib). Jeden rejestr, jedno polecenie instalacji.

Przegladaj biblioteki Jak to dziala
terminal
$ virus install vira pretty-error
pobieranie pretty-error z github.com/vira-io... zainstalowano do cache/libs/vira/pretty-error/
$ echo 'get <vira:pretty-error> import <print_pretty_error>' >> main.hcs

Wpisz nazwe i nacisnij Enter, aby przejsc do pelnej listy z wynikami.

Cztery sposoby dostarczania kodu

Kazda biblioteka deklaruje swoj type - Vira wie, jak go pobrac i podlaczyc.

git

Zrodlo .hcs

Klonowane repozytorium, importowane wprost przez get <vira:nazwa> - kompilowane razem z Twoim projektem.

.a

Static-lib

Gotowy plik .a, linkowany automatycznie przez virus build - uzywasz go przez extern.

.so

Shared-lib

To samo co static-lib, ale dzielona biblioteka .so - podlaczana dynamicznie przy uruchomieniu.

.rlib

Rust-lib

Natywna biblioteka Rusta - podpinana przez .cargo/config.toml, bez pisania wlasnego kodu FFI.

Publikacja jest zwyklym repozytorium git

Zadnego konta, zadnego uploadu - Vira czyta prosto z GitHuba. Dodajesz jeden wpis JSON i Twoja biblioteka jest instalowalna wszedzie.

Przewodnik publikacji
  1. 1 Wrzuc mod.hcs + Virus.hk do repo na GitHubie.
  2. 2 Dodaj wpis { "name", "type", "lib" } do repo-list.json w vira-io/repository.
  3. 3 Otworz pull request - po zmergowaniu biblioteka jest widoczna od reki.
